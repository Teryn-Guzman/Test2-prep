## Project Description

This project contains a Bash shell script called `make-go-dir`.
The script automatically creates a Go API project directory
structure based on two arguments supplied by the user.

## Generated Directory Structure

```text
practice/
├── bin/
├── cmd/
│   └── api/
│       └── main.go
├── internals/
├── migrations/
├── remote/
├── go.mod
└── make-file
```
